Un dossier par sujet

la documentation est rangée à plat par sujet sous Projet/Document/.

DossierContenu
Geneses-Projet-Objectifs/Cadrage : genèse & objectifs SMART.
structure-organisation/Organisation générale, OBS, matrice RACI, carte des compétences, manuel utilisateur.
mvp-pbs-dod/MVP, PBS, WBS, DoD + index de relecture.

risques/Registre des risques.

Convention

Dans chaque dossier : la version HTML (charte) est visible ; les sources .md sont dans archives/. La CSS commune est Document/charte-graphique/archives/flowlearn-document.css.
