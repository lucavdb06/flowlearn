Synthèse exécutive

Ce document consolide les choix technologiques de l'écosystème FlowLearn, alliant performance, flexibilité et intégration profonde de l'Intelligence Artificielle.

L'architecture est construite autour de plusieurs piliers fondamentaux :

  • Infrastructure & Backend : Un noyau FastAPI (Python) performant pour la logique métier et l'IA, soutenu par PostgreSQL / Supabase pour le stockage relationnel et vectoriel (pgvector).
  • Interfaces Multiplateformes : Une base de code React unique, encapsulée par Electron (Desktop) et Capacitor (Mobile), avec Flutter en alternative de repli.
  • Intelligence Artificielle : Un pipeline modulaire orchestrant LiteLLM, PydanticAI, LlamaIndex, LangGraph et CopilotKit.
  • Moteur de Jeu : Godot Engine pour la création de modules ludiques interactifs, connectés au web via export WebAssembly / HTML5.

Détail des rôles IA

Couche Techno Rôle Quand l'utiliser
Gateway LiteLLM Routeur LLM agnostique (local Ollama ou cloud). Simplicité, switch de modèle sans changer le code. Simplifie la gestion des clés.
Orchestration PydanticAI Le Cerveau Logique : résultats structurés et fiables via le typage Python. Traitement de données, interrogation RAG, sorties typées, validation entrées/sorties.
Orchestration LangGraph L'Orchestrateur : graphe de décision, agents autonomes. Flux complexes, agents qui naviguent, corrigent, itèrent sur des processus longs.
Retrieval LlamaIndex Le Bibliothécaire : Indexation, embeddings, recherche RAG. Gestion des cours, PDF, base de connaissances (découpe et recherche sémantique).
UI CopilotKit Intégration front-end IA conversationnelle. Chat, aide à la saisie, interaction fluide côté React.

Recommandation MVP

Hub de jeux hébergés séparément : 1. Développer le jeu séparément.
2. Exporter au format Web (HTML5).
3. Afficher dans React via une URL / iframe.
4. Communication (scores, quiz) via API JSON/JS.

Compatibilité par plateforme

Plateforme Support Notes
Electron (Desktop) Excellent Chrome gère très bien WebAssembly + WebGL.
Capacitor (Mobile) Correct Performances dépendantes du téléphone, restrictions sécurité .wasm.

Points de vigilance Godot

  • Poids : Export Web lourd (plusieurs dizaines de Mo).
  • GPU : Exporter obligatoirement en Compatibility Mode (GLES2/WebGL).
  • Contrôles : Gérer séparément le tactile et clavier/souris.

8. Alternative : Flutter + Godot (Performance & Optimisation)

En cas de problème persistant de performance ou de rendu avec l'iframe Web/Wasm (notamment sur mobile via Capacitor), le couple Flutter + Godot constitue notre alternative de choix.

Performance native
Le moteur de rendu de Flutter et l'intégration native évitent la surcharge et les limites de WebAssembly sur mobile.
Communication fluide
Échange de données bidirectionnel à faible latence (via Method Channels ou plugins natifs comme flutter_godot).
Optimisation ciblée
Gestion fine de la mémoire et du GPU pour un gameplay fluide même sur des terminaux plus modestes.
Hybride Complexe
Idéal pour des apps avec mini-jeux, outils industriels ou éducation hautement interactive.
