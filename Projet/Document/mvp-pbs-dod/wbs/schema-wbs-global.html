§ 03 · Validation

Flux de validation DOD global.

Parcours standard d'une feature : du développement local jusqu'au statut Done sur GitHub Projects.

1
Développement
Branche feature · tests locaux · pull request
01 Dev sur branche
→
02 Tests locaux
→
03 PR GitHub
↓
2
Intégration & revue
Pipeline CI · contrôle cyber et technique
04 CI / Tests auto
→
05 Revue cyber + tech
↓
3
Livraison
DOD validée · merge · clôture projet
06 DOD feature validée
→
07 Merge main
→
08 Done GitHub Projects
Point clé

L'étape 06 est le jalon DOD : la fiche Definition of Done de la feature doit être cochée avant merge. L'étape 08 marque la clôture sur le board projet.
